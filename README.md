## 📋 About the Project

This project is a travel website built to organize and present all the information needed for a family trip to New York, offering a clear itinerary and useful details in an accessible, easy-to-navigate interface.

## 🚀 Features

- 🗓️ Organized travel itinerary
- 🎡 Information about planned activities
- ℹ️ Additional information about the trip
- 📱 Responsive layout
- ♿ Accessible interface
- 🧭 Organized navigation
